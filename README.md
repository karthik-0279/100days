# 100 Days Fitness & Diet Tracker 🏃🥗

A responsive, minimalist dark-themed web application designed for a focused **100-Day Fitness & Diet Protocol**. Built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide Icons** using pure JavaScript (`.jsx` components).

---

## 🌟 The 5 Core Daily Habits Tracked

1. 🥗 **Curd Salad**: Probiotic gut microbiome support, calcium, and protein. Supports custom recipes (Cucumber Mint, Beetroot Raita, Sprouts & Curd) and portion tracking.
2. 🥣 **Oats Breakfast**: Beta-glucan sustained fiber and complex carbs. Includes style variations (Overnight Chia Oats, Warm Porridge, Banana Walnut, Protein Oats) and healthy superfood toppings checklists.
3. 🍃 **Reduced-Sugar Diet**: Refined-sugar detox, insulin sensitivity restoration, and temptation resistance counter.
4. 🏃‍♂️ **Morning Walk & Running**: Cardio tracking with brisk walk, morning run, and interval walk/run modes, real-time distance (km), duration (minutes), step counter, and automated calorie estimation.
5. 💧 **Daily Hydration (3.5 Liters)**: Visual interactive glass tracker (14 glasses × 250ml) with quick +250ml / +500ml logging, progress percentages, and hydration milestones.

---

## ⚡ Key Features

- **100-Day Navigation & Micro Milestones**: Jump to any day from Day 1 to Day 100 with milestone shortcuts (D1, D25, D50, D75, D100).
- **Daily Motivational Quotes**: 10 rotating fitness and discipline quotes to fuel morning habits.
- **100-Day Visual Journey Matrix**: Color-coded bird's-eye view of all 100 days (Gold for 5/5 perfect days, Emerald for 3-4, Blue for in-progress).
- **Lifetime Analytics & Statistics**: Cumulative distance run/walked (km), total steps, total water consumed (Liters), habit adherence breakdown (%), weight loss/gain progress, and active streak counter.
- **Celebration Confetti**: Automatic celebratory confetti particle effects when all 5 habits are conquered for the day.
- **Offline Persistence & Portability**: Automatically stores all 100 days of history in `localStorage`. One-click **JSON Data Export** and **JSON Data Import** for secure backups.
- **Zero TypeScript / Pure JSX**: Built purely with React `.jsx` components for clean customization.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/karthik-0279/100days.git

# Navigate into the project directory
cd 100days

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Building for Production

```bash
npm run build
```

The optimized static production bundle will be output to `/dist`.
